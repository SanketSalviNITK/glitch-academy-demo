# Demo Student's portfolio

**Live site:** https://sanketsalvinitk.github.io/glitch-academy-demo/

This is my portfolio for the Glitch Academy workshop. Over five quests it grows from a README into a 3D portfolio with my own avatar and a chatbot that answers visitors' questions.

## Quests
- [x] Boot Mainframe: Git, GitHub and this README
- [x] Identity Shell: HTML & CSS portfolio
- [x] Holo Projection: a Three.js background
- [x] Chassis Sync: my 3D avatar (assets/avatar.glb)
- [x] Consciousness: a chatbot that answers

## About this repository
An example student portfolio built for the [Glitch Academy](https://sanketsalvinitk.github.io/Gamified_Web_Devlopement_Workshop_GenAI/) workshop. Each commit is one quest, and each was verified live by the workshop's quest checker. Try the chatbot in the bottom-right corner: ask about projects, skills or contact.
